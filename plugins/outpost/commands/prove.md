# /prove

Check claims that must survive scrutiny: numbers going to stakeholders, a contested finding,
a measurement a decision rests on.

Run `prove` over the claims given (or extract the load-bearing claims from the current work
if none are listed). Recompute each from the source of truth, run refutation, and tag every
claim CONFIRMED, QUALIFIED, REFUTED, or UNKNOWN. Never upgrade a verdict to clear the room.
