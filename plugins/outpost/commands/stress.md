# /stress

Challenge a request, plan, answer, or diff before you trust it.

Use the target to choose the prompt. The target also sets intensity: quick for the ask or your
own fresh output, extensive for a design, diff, or plan before commitment.

Pick the prompt by target:
- The ask, before any planning: `interrogate` (quick).
- Your own fresh output, before you present it: `self-refute` (quick).
- A design, plan, or diff you want to trust: `grill` (extensive).
- A plan before commitment: `premortem` (extensive, assume it failed and work backward).

State the target and intensity, then run the prompt and report findings first.
