# /code-review

Review the change in front of you: the working diff by default, or the branch against main
when asked.

Run `code-review` over that diff. Correctness first, then standards. One honest verdict at
the end: approve, comment, or request changes, with the blocking findings listed
first.

For a hostile pass that tries to break the design rather than check it, use `grill` instead.
