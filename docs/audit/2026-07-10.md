# ACK Phase 1 audit

> Superseded 2026-07-11. The owner ruled on this audit in
> [ADR-0014](decisions/0014-pack-consolidation.md), and the accepted fixes shipped (see the
> Unreleased section of [CHANGELOG.md](../CHANGELOG.md)). Read this as a point-in-time record, not
> a live worklist: several findings below are closed, and the scorecard predates the `deassume`
> removal and the 24-prompt count. Do not re-work a finding without checking the changelog first.

ACK's repository gate proves source and generated-file coherence, but it does not prove that each
tool reads the installed files or that the prompt contracts produce safe results. The first repair
wave should protect user files and make the four installed surfaces load what ACK says they load.
(verified)

## Ranked findings

### F1 [critical] Cursor does not discover the installed prompt pack (verified file contract; live Cursor load unknown)

- Finding: the adapter writes 25 plain `.md` files under `.cursor/rules/ack/`. Cursor project rules
  are `.mdc` files, so the one top-level `ack.mdc` rule is the only native rule in the install.
- Evidence: `kit/adapters/cursor/__init__.py:17-30`, `tests/test_adapters.py:26-35`,
  `prompts/cursor/README.md:3`, and [Cursor rules](https://docs.cursor.com/context/rules).
- Cheapest falsifier: install into a fresh repo and count the ACK entries Cursor reports as project
  rules. The current adapter should expose 26 if its claim is true.

### F2 [critical] Path-based ownership can overwrite or delete user files (verified)

- Finding: the installer treats a reserved path or matching bytes as proof of kit ownership. It
  does not record whether a guide, prompt path, or settings rule existed before install.
- Evidence: `install.py:391-418`, `install.py:317-348`, `kit/installers/manifest.py:17-36`, and
  `kit/installers/settings.py:72-101`.
- Probe: a pre-existing Copilot prompt was overwritten on first install. A pre-existing `AGENTS.md`
  identical to the template was deleted by `--remove`. An edited legacy Cursor file was deleted by
  `--prune` in isolated temporary targets.
- Cheapest falsifier: repeat those three probes and show that every pre-existing byte survives.

### F3 [major] One generated Claude skill has invalid YAML metadata (verified)

- Finding: `converge` has an unquoted colon in its description. Claude drops all frontmatter
  metadata, so load-by-description does not work for that skill.
- Evidence: `prompts/core/converge.md:3`, `plugins/ack/skills/converge/SKILL.md:3`, and the regex
  parser at `kit/checks/__init__.py:48-55`.
- Cheapest falsifier: run `claude plugin validate plugins/ack`. Claude Code 2.1.207 exits 1 on
  `converge`, while `python validate.py` stays green.

### F4 [major] Five hand-authored plugin commands are shadowed (verified inventory; precedence direction unknown)

- Finding: `code-review`, `prove`, `repo-review`, `simplify`, and `triage` exist once as generated
  skills and again as flat command files. Claude gives the skill precedence over the same-name
  command, so the wrapper's defaults are not a reliable entry point.
- Evidence: `plugins/ack/skills/`, `plugins/ack/commands/`,
  [Claude skill precedence](https://code.claude.com/docs/en/slash-commands), and live
  `claude plugin details ack@ack`, which lists all five names twice among 34 skills.
- Cheapest falsifier: invoke each `/ack:<name>` and show that the flat command body, not the
  generated skill body, is the loaded instruction.

### F5 [major] Plugin install and command names are documented incorrectly (verified)

- Finding: plugin skills and commands are namespaced as `/ack:*`, but current docs and the
  `command_lists` check require bare names. The documented local `/plugin install <path>` form is
  not the local development path supported by Claude.
- Evidence: `README.md:83-95`, `docs/plugin.md:5-18,23-32`, `docs/when-to-use.md:15,37`,
  `docs/decisions/0010-the-kit-is-ack.md:12-13`, and
  [Claude plugin development](https://code.claude.com/docs/en/plugins).
- Cheapest falsifier: load `ack@ack`, open `/help`, and invoke both `/stress` and `/ack:stress`.

### F6 [major] Source validation is presented as target-install verification (verified)

- Finding: `python validate.py` always checks the ACK source tree. It does not detect a missing or
  edited file in a consumer repo. The installed `/ack:doctor` command repeats that source-only
  command in repos that normally have no `validate.py`.
- Evidence: `README.md:50-54,129-131`, `docs/onboarding.md:30-32`, `docs/ROADMAP.md:24`,
  `validate.py:14-15`, `install.py:428-448,499-536`, and `plugins/ack/commands/doctor.md:7-9`.
- Cheapest falsifier: delete one installed prompt, run ACK's gate, then run
  `python install.py --tool <tool> --project <target> --verify`.

### F7 [major] The Codex adapter ignores Codex's native workflow surface (verified file contract; live Codex discovery unknown)

- Finding: ACK says Codex has no skills and installs manual files under `.agents/prompts/`.
  Current Codex discovers repo skills under `.agents/skills/<name>/SKILL.md` and loads their
  metadata on demand.
- Evidence: `kit/adapters/codex/__init__.py:1-3,23-29`, `docs/adapters.md:20,36-37`, and
  [Codex customization](https://developers.openai.com/codex/concepts/customization).
- Cheapest falsifier: compare a fresh ACK Codex install with the skill list Codex discovers.

### F8 [major] Generated guides advertise only 8 of 25 prompts (verified)

- Finding: the shared guide source names eight prompts. The Codex and Copilot overlay docs say
  their guides list each core prompt, its trigger, and its file.
- Evidence: `templates/_src/core.md:5-16`, `templates/AGENTS.md:10-21`,
  `templates/copilot-instructions.md:11-22`, `prompts/codex/README.md:3`, and
  `prompts/copilot/README.md:3`.
- Cheapest falsifier: count prompt names, descriptions, and file links in each installed guide.

### F9 [major] The README quick start installs into ACK itself (verified)

- Finding: the command uses `--project .` without a clone and working-directory sequence. In a
  clean ACK copy it creates `.ack`, `.agents`, `.claude`, `.cursor`, `.github` files, and
  `AGENTS.md` inside the kit checkout.
- Evidence: `README.md:29-34`, `install.py:492-495`, and the separate target shown at
  `docs/onboarding.md:7-9`.
- Cheapest falsifier: follow the README from a clean clone and require a clean `git status`.

### F10 [major] ACK tests packaging, not prompt effectiveness (verified)

- Finding: the ROADMAP calls a clean install plus the repository gate proof that ACK works. The
  prompt check states that it proves form, not quality.
- Evidence: `docs/ROADMAP.md:24`, `kit/checks/prompts.py:1-4,16-38`, and
  `docs/dogfooding.md:7-23`.
- Cheapest falsifier: show one outcome test that fails when a prompt is well-shaped but gives a
  wrong or unsafe instruction.

### F11 [minor] The intended audience is unresolved (verified)

- Finding: the opening reads like a product page for teams, while the license and package metadata
  limit use to AGI. A top-of-file badge marks the license internal, but the prose states the
  restriction only in its final line.
- Evidence: `README.md:8,17-21,118-139`, `LICENSE:1-5`, `pyproject.toml:8-12`, and
  `docs/ROADMAP.md:48-50`.
- Cheapest falsifier: an owner ruling names either AGI teammates or outside users as the supported
  audience and states the matching license and support path.

### F12 [major] Prompt admission has no rule that covers current growth (verified)

- Finding: ADR-0002 requires a new decision before widening scrutiny. ADR-0011 records a 24-prompt
  pack. `deassume` makes 25, but ADR-0012 decides trace handling rather than prompt admission.
- Evidence: `docs/decisions/0002-scrutiny-prompts.md:27-31`,
  `docs/decisions/0011-review-suite.md:9-27`, `docs/decisions/0012-no-personal-traces.md:13-19`,
  `CHANGELOG.md:9-14,291-295`, and `docs/ROADMAP.md:40`.
- Cheapest falsifier: point to an accepted decision that admits `deassume`, `prove`, and `panel`
  under a repeatable prompt-entry test.

### F13 [major] The stated workflow boundary contradicts the shipped prompts (verified)

- Finding: `when-to-use` says ACK starts after work is defined, but `interrogate` defines the
  request, audience, success test, and non-goals. `workflow` also calls a list read-only while it
  includes `split-change` and `respond-to-review`, which write.
- Evidence: `docs/when-to-use.md:7-8,21-23,39-41`, `docs/workflow.md:17-24`,
  `prompts/core/interrogate.md:8-16,25-40`, `prompts/core/split-change.md:24-28`, and
  `prompts/core/respond-to-review.md:24-34`.
- Cheapest falsifier: define upstream shaping and read-only so both statements hold without an
  exception.

### F14 [major] Mutating prompts omit the authority they need (verified)

- Finding: `split-change` stages and commits. `respond-to-review` edits, posts, and re-requests
  review. `triage` writes debt entries. Their required inputs do not ask for write authority,
  branch state, or external connectivity.
- Evidence: `prompts/core/split-change.md:17-28`, `prompts/core/respond-to-review.md:17-28`, and
  `prompts/core/triage.md:18-35,48-52`.
- Cheapest falsifier: run each on a dirty protected branch with read-only review access and require
  a useful non-mutating result.

### F15 [major] `converge` has two definitions of clean (verified)

- Finding: its description promises every issue fixed. Its steps and stop rule declare clean when
  blockers and majors reach zero, even when confirmed minors remain.
- Evidence: `prompts/core/converge.md:3,8-10,25-30,39-44`.
- Cheapest falsifier: give it one confirmed minor and no higher finding, then inspect the final
  state.

### F16 [major] `prove` turns uncertainty into refutation and assumes subagents (verified)

- Finding: a skeptic defaults to REFUTED when unsure, while the output reserves UNKNOWN for data
  that cannot decide. The prompt and `panel` require parallel independent agents with no sequential
  fallback for a host that cannot spawn them.
- Evidence: `prompts/core/prove.md:27-55`, `prompts/core/panel.md:18-43`, and the manual-file
  adapter model at `README.md:118-127`.
- Cheapest falsifier: run both prompts through all four adapters with an unavailable source and
  require an UNKNOWN verdict plus evidence of view independence.

### F17 [major] `write-tests` mandates an integration test for every change (verified)

- Finding: the prompt has no exception for a pure helper, compile-time contract, or repo with no
  integration consumer. Its stop condition still requires all named groups.
- Evidence: `prompts/core/write-tests.md:8-10,22-28,36-40`.
- Cheapest falsifier: apply it to a private pure function with no integration harness and name the
  valid consumer test.

### F18 [minor] `refactor-safely` does not report its coverage basis (verified)

- Finding: the prompt asks for characterization tests when coverage is weak. Its output contract
  records only that the same tests passed, so it does not expose which behavior those tests cover.
- Evidence: `prompts/core/refactor-safely.md:8,20-26,28-37`.
- Cheapest falsifier: require the output to name each touched behavior and its covering test, then
  show that the current output already supplies that evidence.

### F19 [minor] `debug-failure` leaves before-fix proof implicit (verified)

- Finding: the steps add the regression test after the fix. The output requires a before-fix result,
  but no step says how to replay the prior state safely.
- Evidence: `prompts/core/debug-failure.md:20-33`.
- Cheapest falsifier: start from an already fixed tree with no safe revert and require real
  before-fix evidence.

### F20 [major] Two writing prompts lack a usable destination contract (verified)

- Finding: `write-doc` promises a tested template but does not require one. `debt-log` says to
  append at the repo root, while ACK's own ledger is `docs/DEBT.md`.
- Evidence: `prompts/core/write-doc.md:8-9,19-40`, `prompts/core/debt-log.md:26-44`, and
  `docs/DEBT.md:1-11`.
- Cheapest falsifier: invoke each in ACK without a supplied template or destination and inspect the
  planned file.

### F21 [major] The docs gate omits shipped docs (verified)

- Finding: the gate's 12-doc total is not the ROADMAP's 12-doc product set. `token-budget`,
  `dogfooding`, `DEBT`, and accepted ADRs are outside both required-doc lists.
- Evidence: `kit/checks/docs.py:7-20`, `kit/checks/structure.py:7-16`, and
  `docs/ROADMAP.md:19-20`.
- Probe: removing `docs/token-budget.md`, `docs/dogfooding.md`, and `docs/DEBT.md` with `git rm`
  in an isolated copy still produced 17/17 (a plain filesystem delete instead trips the secrets
  and traces checks' fail-closed unreadable errors, not a docs-coverage failure).
- Cheapest falsifier: delete any excluded shipped doc in a disposable copy and make the gate fail.

### F22 [major] Generated parity checks do not reject extras (verified)

- Finding: `plugin_sync` checks expected files in one direction only. Tool overlays also accept a
  new name instead of requiring a same-name core override.
- Evidence: `kit/checks/plugin_sync.py:28-41`, `kit/adapters/base.py:61-78`, and
  `kit/checks/catalog.py:29-45`.
- Probe: an extra plugin skill and an extra Codex overlay both survived the full gate in an
  isolated copy.
- Cheapest falsifier: seed either extra and require a named gate failure.

### F23 [major] `doc_truth` skips single-word prompt names (verified)

- Finding: the active regex requires a hyphen, so `grill`, `prove`, `panel`, `triage`, and
  `converge` can drift to other one-word names without a failure.
- Evidence: `kit/checks/doc_truth.py:27-31,73-90`.
- Cheapest falsifier: change `grill` to a nonexistent one-word name in `docs/workflow.md` and run
  the check.

### F24 [major] Plain ASCII is stated but not enforced (verified)

- Finding: the voice check rejects two Unicode dash characters and a word list. Other non-ASCII
  text passes.
- Evidence: `docs/writing-standard.md:7-19`, `docs/contributing.md:7-8`, and
  `kit/checks/voice.py:12-38`.
- Cheapest falsifier: add a different non-ASCII character to tracked Markdown and run the gate.

### F25 [major] Secret and personal-trace checks are pattern samples, not the rule (verified)

- Finding: secrets covers private keys and one AWS key shape. Traces covers one owner's markers.
  Common token shapes and another contributor's email or home path pass.
- Evidence: `kit/checks/secrets.py:1-24`, `kit/checks/traces.py:1-26`, and
  `docs/decisions/0012-no-personal-traces.md:13-19,29-33`.
- Probe: a fake GitHub-token-shaped string and `/Users/alice/project` survived 17/17 in an isolated
  copy. A broader read-only scan found no current credential-shaped hit in the tracked tree.
- Cheapest falsifier: seed representative formats from the stated rule and require each to fail.

### F26 [minor] Contributor and release recipes are incomplete (verified)

- Finding: adding a prompt omits plugin and doc generation. Adding a check omits ROADMAP generation.
  Adding an adapter omits user-facing tool tables. The release recipe omits the ROADMAP version
  update and a final gate run.
- Evidence: `docs/contributing.md:10-48`, `docs/releasing.md:23-31`,
  `kit/checks/roadmap.py:31-40`, and `tools/build_plugin.py:1-22`.
- Cheapest falsifier: follow one recipe literally in a disposable copy and require the gate to pass.

### F27 [minor] Token-budget evidence tags overstate their sources (verified)

- Finding: an issue report is labeled primary evidence. Subset install is proposed in one section
  and verified in another. Pricing proves price differences, not the task-to-model routing rule.
- Evidence: `docs/token-budget.md:5,11,22-27,33-34,49-57`.
- Cheapest falsifier: provide a primary source or an ACK benchmark for each operational effect.

### F28 [major] Plugin components depend on ACK-source assumptions (verified)

- Finding: the context hook points to `docs/token-budget.md`, which is outside the cached plugin.
  The hook requires a `python` executable without a stated plugin prerequisite. The code-review
  wrapper also assumes the base branch is `main`.
- Evidence: `plugins/ack/hooks/nudge_context.py:35-42`, `plugins/ack/hooks/hooks.json:1-12`,
  `plugins/ack/commands/code-review.md:7-10`, and
  [Claude plugin file isolation](https://code.claude.com/docs/en/plugins-reference).
- Cheapest falsifier: use the plugin in a non-ACK repo whose base is not `main` and whose Python
  executable is only `python3`.

### F29 [minor] The PR claim is wider than the prompt contract (verified)

- Finding: the ROADMAP says ACK opens a PR. `prepare-pr` drafts text and explicitly leaves opening
  the PR to a human.
- Evidence: `docs/ROADMAP.md:5`, `docs/workflow.md:14`, and
  `prompts/core/prepare-pr.md:8,30-39`.
- Cheapest falsifier: invoke `prepare-pr` and show the created PR URL.

### F30 [minor] Repeated hand-owned inventories invite drift (verified)

- Finding: install paths and command names are copied across README, onboarding, adapters, plugin,
  when-to-use, ROADMAP, and templates. Current generators protect only some spans.
- Evidence: `README.md:56-60,83-95,118-127`, `docs/onboarding.md:11-22`,
  `docs/plugin.md:20-32`, `docs/ROADMAP.md:13-22`, and `kit/docs_build.py:28-33`.
- Cheapest falsifier: change one command or path at the source and list every copy the generators
  update.

### F31 [minor] Three naming surfaces still disagree (verified facts; resolution unknown)

- Finding: the flow image calls prompts skills for all four tools. The hook keeps the old
  `AGI_KIT_NUDGE_BYTES` prefix. The README names five maintainers while CODEOWNERS lists six handles.
- Evidence: `docs/brand/flow.svg:66`, `plugins/ack/hooks/nudge_context.py:6,17`,
  `README.md:21`, and `.github/CODEOWNERS:2`.
- Cheapest falsifier: apply the vocabulary ruling, name the supported environment variable, and map
  each CODEOWNER to the current maintainer roster.

### F32 [major] A terse-to-plain reinstall leaves stale state (verified)

- Finding: reinstalling Claude without `--terse` records `terse: false`, but it does not remove the
  prior output-style file or clear `outputStyle`. Later verification forgets to inspect that state.
- Evidence: `kit/adapters/claude/__init__.py:34-50`, `kit/installers/settings.py:54-56`,
  `install.py:88-101,507-524`, and `tests/test_install.py:708-712`.
- Cheapest falsifier: install with `--terse`, reinstall without it, and require both the file and
  settings key to be gone before `--verify` passes.

### F33 [minor] Catalog entry shape and uniqueness are not enforced (verified)

- Finding: the loader checks top-level fields but not duplicate prompt, adapter, check, or template
  entries. Later set conversions can hide a duplicate while counts or execution change.
- Evidence: `kit/catalog/loader.py:33-58` and the set comparisons in `kit/checks/catalog.py` and
  `kit/checks/registries.py`.
- Cheapest falsifier: duplicate one catalog entry in a disposable copy and require catalog loading
  to fail before generation or check execution.

### F34 [minor] Copilot support is narrower than the tool label (verified)

- Finding: `.prompt.md` files are supported in the named IDE integrations, but the README's broad
  GitHub Copilot label can imply the same path works in every Copilot surface. Reader paths can also
  overlap even when adapter write paths do not.
- Evidence: `README.md:118-125`, `prompts/copilot/README.md:3`, `tests/test_adapters.py:17-35`, and
  [GitHub prompt files](https://docs.github.com/en/copilot/tutorials/customization-library/prompt-files/your-first-prompt-file).
- Cheapest falsifier: inspect the installed customizations in VS Code, Copilot CLI, and the coding
  agent after `--tool all`.
