# ADR 0001: Initial architecture baseline

## Status

Accepted.

## Context

This repo joined fleet doctrine CI. A first ADR establishes the architecture
ledger required by the anti-rot gate.

## Decision

Track architecture decisions under `docs/adr/`. Prefer short ADRs that name
the constraint and the chosen boundary.

## Consequences

New structural choices get an ADR before they spread across the tree.
