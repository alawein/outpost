# Outpost

Windsurf loads this rule on every turn from `.windsurf/rules/outpost.md`. The prompts install as
workflows under `.windsurf/workflows/`, invoked as `/outpost-<name>`. Read this at the start of a
session. Replace the bracketed text for your project, then delete it.
